# Simple Shell

## Description

Simple Shell is a project developed as part of the Holberton Coding School curriculum.
The goal of this project is to create a simple UNIX command line interpreter written in C.

The shell reads commands entered by the user, executes them, and displays the result.

## Compilation

The shell will be compiled using:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o hsh

## Usage

Run the shell in interactive mode:

./hsh

Example:

$ /bin/ls

To exit the shell:

$ exit
